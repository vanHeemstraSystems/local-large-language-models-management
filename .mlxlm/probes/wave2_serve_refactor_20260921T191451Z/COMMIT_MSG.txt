feat(mlxlm): Wave 2 — model-selectable serve.sh (macOS Bash 3.2-safe)

Refactor .mlxlm/serve.sh so the warm-default model is the validated local
Qwen3-8B-4bit and the model is selectable via a single, testable env var,
without introducing any Bash-4-only syntax or unsupported mlx-lm 0.31.3
server flags.

Runtime changes (this commit)
- .mlxlm/serve.sh: rewritten as a Bash 3.2-safe script (macOS /bin/bash 3.2.57).
  * New env var MLXLM_SERVE_MODEL selects the warm model (default: qwen3-8b).
  * Model registry via a case-based resolve_model() helper (no declare -A,
    no mapfile/readarray, no ${var,,}, no [[ =~ PCRE).
  * Alias table today: qwen3-8b -> ~/.mlx-serve/models/mlx-community/Qwen3-8B-4bit.
    Unknown alias -> exit 2 with a clear error; the server is NOT started
    and no PID file is written.
  * Missing model dir on disk -> exit 3.
  * Preserved subcommands: start, stop, status, log (behavior identical).
  * Additive subcommand: models (prints the supported alias table).
  * Header comment corrected: mlx-lm 0.31.3 on Python 3.12 (was stale 0.29.1).
